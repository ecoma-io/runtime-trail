# 1.0 gate checklist

> Machine-checkable 1.0 acceptance for `runtime-trail`. Each row names the
> exact gate — a test, a command, or a fixture — that proves the criterion;
> the status is filled from a run on the stated date, never from assumption.
> `passing` = the named gate ran green; `blocked` = a tracked defect or gap
> stops it; `planned` = the phase owning it has not started. Owner documents
> are the architecture authority table in the repository AGENTS.md. Rerun
> the gate — never trust the row.
